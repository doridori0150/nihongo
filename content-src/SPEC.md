# 콘텐츠 작성 규격 (nihongo-daily)

학습자: 한국어 화자, JLPT N2 이상을 목표로 하는 중상급자.
목표: 여행·일상 회화 + 드라마/애니/만화/소설에서 실제로 들을 법한 자연스러운 일본어.
설명·번역·메모는 모두 **한국어**로 작성.

## 저작권 규칙 (중요)
- 실제 드라마·애니·만화·소설의 대사/문장을 인용하거나 흉내 내어 재현하지 말 것.
- 실존 작품명, 등장인물 이름, 유명 대사 금지. **모두 직접 창작한 문장**이어야 함.
- `src`는 "그런 장르에서 나올 법한 말투/장면"이라는 스타일 표시일 뿐이다.

## JText 표기법 (일본어 문장 필드 전부: jp, line, question, opening)
1. **모든 한자**에 후리가나를 단다: 한자 덩어리 바로 뒤에 `{읽기}`.
   - `見当{けんとう}`, `取{と}り扱{あつか}い`, `今日{きょう}`, `一人{ひとり}`, `何分{なんぷん}`
   - 오쿠리가나는 괄호 밖: `食{た}べる`, `諦{あきら}めた`
   - 읽기는 히라가나(외래어 표기 시 가타카나)만. 숫자는 아라비아 숫자 가능(후리가나 불필요).
   - `ヶ`는 쓰지 말고 `か`로: `3か月{げつ}`
2. **청크 구분** `|` : 문장 조립 퀴즈용. 자연스러운 문절(文節) 단위로 3~9개 청크.
   - 구두점(、。！？)은 앞 청크에 붙인다. 문장 앞뒤에 `|` 금지, `||` 금지.
   - 예: `犯人{はんにん}が|誰{だれ}なのか、|まったく|見当{けんとう}も|つかない。`
3. 일본어 따옴표 「」는 사용 가능. 큰따옴표 `"` 는 JSON 이스케이프 문제로 사용 금지.

## src (장면 스타일) — 다음 중 하나
`drama`(드라마풍), `anime`(애니풍), `manga`(만화풍), `novel`(소설풍 서술), `daily`(일상 회화), `travel`(여행 중)
- 한 단어의 예문 2개는 서로 다른 src 사용. 파일 전체에서 고르게 섞을 것.
- `scene`: 한국어로 짧은 장면 설명. 예: "형사 드라마 – 수사 회의에서 반장이 한숨 쉬며", "소설 – 비 오는 밤 귀갓길 묘사", "여행 중 – 료칸 프런트에서 체크인하며"
- 말투를 장면에 맞게: 친구끼리는 반말(タメ口), 점원·윗사람은 경어, 소설은 문어체 서술(だ・である체 등) 등. 남녀 말투, 간사이벤 등도 가끔 섞어도 좋음(그런 경우 note나 scene에 명시).

## cloze (빈칸 문제)
- `target`: 해당 예문의 순수 텍스트(후리가나·| 제거한 것) 안에 **그대로 존재하는** 문자열. 활용형이면 활용된 그대로. (`{}` `|` 넣지 말 것)
- `distractors`: 오답 3개. 정답과 **같은 품사·같은 활용형·비슷한 길이**로, 그럴듯하지만 그 문맥에서는 틀린 것. (JLPT 문제 스타일) 정답과 사실상 같은 의미가 되어 버리는 오답은 금지.

```
node scripts/validate-content.mjs <vocab|grammar|phrases|qa> <파일들>
```
