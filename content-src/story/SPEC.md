# 스토리 회차 작성 규격

먼저 읽을 것: `docs/story/BIBLE.md` (세계관·인물 말투·회차 목록), `content-src/SPEC.md` 의 JText 표기법.

## 파일
`content-src/story/y1/<id>.json` — 회차 하나당 파일 하나 (예: `y1-01.json`).

```json
{
  "id": "y1-01",
  "year": 1,
  "month": 4,
  "no": 1,
  "title": "桜{さくら}と迷子{まいご}",
  "title_ko": "벚꽃과 미아",
  "summary_ko": "입학식 날 길을 잃은 주인공. 같은 반 히요리에게 한 살 많다는 게 들통나고…",
  "level": "N3",
  "focus": ["자기소개 하기", "〜はどこですか 로 길 묻기"],
  "terms": [
    { "jp": "自己紹介{じこしょうかい}", "ko": "자기소개", "note": "한국어 한 문장 설명(쓰임·뉘앙스)" }
  ],
  "script": [
    { "bg": "school_gate" },
    { "narr": "四月{しがつ}。|桜{さくら}が|満開{まんかい}だった。", "ko": "4월. 벚꽃이 만개해 있었다." },
    { "show": "hiyori", "face": "smug" },
    { "say": "hiyori", "face": "smug", "jp": "ねえ、|迷子{まいご}？", "ko": "저기, 길 잃었어?" },
    { "say": "me", "jp": "あの、|体育館{たいいくかん}は|どこですか？", "ko": "저기, 체육관은 어디예요?" },
    { "say": "npc", "who": "担任の先生", "who_ko": "담임 선생님", "jp": "…", "ko": "…" },
    {
      "choice": "히요리가 놀린다. 뭐라고 받아칠까?",
      "options": [
        { "jp": "…", "ko": "…", "ok": true, "aff": { "hiyori": 1 }, "then": [ { "say": "hiyori", "jp": "…", "ko": "…" } ] },
        { "jp": "…", "ko": "…", "ok": false, "tip": "왜 어색한지 한국어로 1~2문장", "then": [ { "say": "hiyori", "jp": "…", "ko": "…" } ] }
      ]
    },
    { "if_aff": { "hiyori": 3 }, "then": [ { "say": "hiyori", "jp": "…", "ko": "…" } ], "else": [ { "say": "hiyori", "jp": "…", "ko": "…" } ] },
    { "hide": "hiyori" }
  ]
}
```

## 스크립트 명령
- `bg`: 배경 전환. 값은 BIBLE의 배경 키 중 하나.
- `show` / `hide`: 캐릭터 등장·퇴장 (동시에 최대 2명). `face`: normal / happy / angry / sad / surprised / smug / shy.
- `narr`: 지문(일본어, 소설 지문체가 아니라 짧고 쉬운 설명체), `ko` 필수.
- `say`: 대사. 값은 `me`(주인공), 캐스트 id(saeko, minato, shizuku, ritsu, hiyori), 또는 `npc`(+ `who` 일본어 이름, `who_ko`). `face` 선택.
- `choice`: 선택지 2개. `ok:false` 쪽은 학습자가 실제로 할 법한 실수(경어 실수, 조사·활용 실수, 상황에 안 맞는 말투)로 만들고 `tip`에 이유를 한국어로. 각 옵션은 `then`(반응 대사 1~3개) 필수, 선택지가 끝나면 본편으로 합류.
- `if_aff`: 친밀도 조건 분기(선택). 해당 캐릭터 친밀도가 값 이상이면 `then`, 아니면 `else`.
- `if_top`: 가장 친한 부원 분기(엔딩용). `{ "if_top": ["hiyori","akane",…], "branches": { "hiyori": [ … ], … }, "else": [ … ] }` — 목록 중 친밀도가 가장 높은 캐릭터의 branch를 실행(동점이면 목록 앞쪽). branch가 없는 캐릭터가 있으면 `else` 필수. `"year": 3`을 붙이면 그 학년 선택지에서 얻은 친밀도만 센다(엔딩이 그 해의 선택을 반영하도록).
- 관계 선택지: 두 답이 모두 자연스러운 일본어(`ok: true` 둘 다, tip 없음)이고 `aff`가 서로 다른 부원에게 가는 선택지. "누구를 도울까/누구 편을 들까"처럼 플레이어의 취향이 친밀도에 반영된다.

## 작성 규칙
- 분량: script 45~80 단계, 선택지 2~3개, terms 8~15개.
- 모든 일본어(jp, narr, title, terms.jp, 선택지 jp)는 JText(한자 전부 후리가나). 청크 `|` 는 넣어도 되고 안 넣어도 됨.
- 주인공 이름은 `%name%`, 남/여 호칭은 `%kun%` (くん/さん 자동). 예: `%name%%kun%`, 사에코는 `%name%`, 히요리는 `センパイ`. ko 에도 `%name%` 사용.
- terms 의 단어·표현은 **반드시 대본 속 대사나 지문에 그대로 등장**해야 한다(후리가나 뺀 글자 기준). 회차 학습 포인트(BIBLE 표)를 중심으로.
- 대사는 짧게(대부분 40자 이하), 실제 회화체. 캐릭터 말투를 BIBLE 그대로 지킬 것(시즈쿠 「…ふひ」, 리츠 「〜じゃん」, 히요리 「ざーこ♪」, 사에코 한숨·반말, 미나토 냉정한 반말).
- 학년·월에 맞는 난이도(BIBLE 참고). 너무 어려운 한자어는 지문보다 대사로 자연스럽게.
- 오리지널 스토리만. 실존 작품의 대사 인용 금지. 작품 속 애니는 가상의 작품 사용: 『星屑{ほしくず}のメロディア』(음악 애니), 『鋼鉄{こうてつ}騎士{きし}ガルバード』(로봇), 『魔法少女{まほうしょうじょ}☆ルミナ』, 『放課後{ほうかご}ロケット』(일상계). 코미케·아키하바라 같은 실제 장소·행사는 OK.
- 개그와 위트를 섞되 따뜻하게. 성적 묘사·노골적 연애 금지(학생끼리 풋풋한 정도), 선생님과 연애 요소 금지.
- 회차 끝은 다음 화로 이어지는 한 줄 여운.
